# Kebijakan Privasi Anti DumbScroll

Terakhir diperbarui: [Tanggal Sekarang]

Privasi Anda sangat penting bagi kami. Kebijakan Privasi ini menjelaskan bagaimana Anti DumbScroll memproses data Anda.

## 1. Pengumpulan Data
Anti DumbScroll **tidak mengumpulkan, mengirim, atau membagikan** data pribadi, riwayat penjelajahan, atau data penggunaan aplikasi Anda ke server mana pun. Semua data yang dihasilkan oleh aplikasi disimpan sepenuhnya secara lokal di perangkat Anda menggunakan `SharedPreferences`.

## 2. Penggunaan Layanan Aksesibilitas
Aplikasi ini menggunakan **Layanan Aksesibilitas (Accessibility Service)** semata-mata untuk mendeteksi nama paket (*package name*) aplikasi yang sedang aktif atau berada di layar utama.
- Layanan Aksesibilitas **tidak** digunakan untuk membaca isi layar, pesan, kata sandi, atau data sensitif lainnya.
- Data yang dideteksi (nama aplikasi) hanya digunakan untuk mencatat durasi penggunaan (waktu) dan menonaktifkan aplikasi media sosial yang telah Anda tentukan.

## 3. Izin Aplikasi
- **POST_NOTIFICATIONS**: Digunakan untuk menampilkan notifikasi timer Pomodoro atau informasi waktu layar.
- **SYSTEM_ALERT_WINDOW (Overlay)**: Digunakan untuk menampilkan pesan pemblokiran layar atau peringatan ketika batas waktu terlampaui.

## 4. Keamanan Data
Karena kami tidak mengumpulkan data apa pun, kami tidak dapat membagikan atau membocorkan data Anda kepada pihak ketiga. Pengaturan, riwayat waktu layar, dan daftar aplikasi diawasi sepenuhnya ada dalam kontrol Anda di perangkat Anda sendiri. Jika Anda menghapus aplikasi, seluruh datanya juga akan terhapus.
